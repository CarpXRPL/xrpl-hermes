# Standalone bundle — retired

The former generated standalone document embedded stale copies of knowledge articles and direct seed/sign/submit examples. It is intentionally retired because duplicated protocol and provider guidance drifts from the canonical repository.

Use:

- `README.md` for project scope;
- `SKILL.md` for command discovery and safety rules;
- `knowledge/` and `references/` for current certification cards;
- `scripts/xrpl_tools.py` for CLI execution;
- `scripts/mcp_server.py` for the default-deny MCP surface.

XRPL-Hermes builds unsigned intent, user-owned external wallets sign, and Hermes verifies validated results. Do not redistribute an old standalone copy.
